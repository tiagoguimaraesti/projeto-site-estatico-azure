# Projeto Site Estatico no Azure
## Etapa 1: Grupo de Recursos
Criado o Resource Group 'rg-gp-static-website' para organizar e gerenciar o ciclo de vida da infraestrutura.
## Etapa 2: Conta de Armazenamento
Provisionada uma Storage Account com redundância LRS (Locally Redundant Storage) para garantir baixo custo e armazenar os arquivos do site.
## Etapa 3: Hospedagem de Site Estatico
Recurso ativado com sucesso. O Azure criou automaticamente o conteiner $web e gerou o Endpoint publico do site.
